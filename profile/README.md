SWAY — игровое Discord-сообщество с июля 2023 года. Здесь играют в CS 2, osu!, Minecraft, Dota 2, Genshin Impact и Path of Exile, слушают музыку и просто общаются. Боты сообщества написаны своими силами, двое из них открыты для всех серверов.

> Исходный код ботов закрыт. Здесь мы публикуем дорожную карту, принимаем баг-репорты и идеи.
